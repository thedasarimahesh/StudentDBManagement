# 📚 Student Management System (Python)

## 📌 Overview

The Student Management System is a console-based Python application for managing student records. It provides a menu-driven interface to add, view, modify, and delete records. Student data can be saved to and loaded from a text file so it is available across program runs.

## 🚀 Features

- ➕ Add student names and marks
- 📄 View all student records
- ✏️ Modify a student's name and marks by roll number, or marks by name
- ❌ Delete a student by roll number or name
- 🧹 Delete all student records
- 🔄 Reverse the order of the student list
- 💾 Save records to `Studentdata.txt` and load them when the program starts
- 🚪 Exit the program

## 🛠️ Technologies Used

- Python 3.10 or above
- Console-based interface
- Text-file storage

## 🧠 Concepts Used

- Classes and objects
- Dataclasses and type annotations
- Singly linked lists
- Conditional statements and loops
- Exception handling
- File handling

## ▶️ How to Run

Open a terminal in the project directory and run:

```bash
python dbcode.py
```

On Windows, you can also use:

```powershell
py dbcode.py
```

The program creates or reads `Studentdata.txt` in the current working directory when saving or loading records.
